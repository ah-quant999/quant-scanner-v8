🧭一、选股四模块总览

v8 选股体系由四个互补模块构成，按"胜率优先、趋势质量、全市场扫描、弱市防御"分层：

模块定位核心入选条件前端入口
🥇 三重共识 短线事件/共识驱动，胜率优先 主站 TOP10 评分 ≥70 + 驾驶舱 A 档 + 基本面 A 档；扩展池为差 1~2 步备选 选股策略 · 三重共识
🎯 驾驶舱 A/B 档 中长线趋势质量 多因子评分：趋势强度、波动率、资金流向、基本面过滤后分 A/B 两档 驾驶舱（主模块）/ 选股策略 · 驾驶舱
🔗 全站精选 全市场扫描，跨模块重叠验证 多重算法同时命中的标的聚合，用于观察模块间重叠度与持续跟踪 选股策略 · 全站精选
📊 逆势龙头（CRDS） 弱市/大跌日防御型选股 大盘或板块显著下跌时，筛选相对强度领先、资金逆势承接的龙头 选股策略 · 逆势龙头

🛡️三、数据口径与校验层级

3.1 数据源

  • A 股行情与基本面：腾讯 GTimg / akshare（云端适配境外环境）
  • 板块/概念资金：东方财富资金流接口
  • 北向/融资融券/龙虎榜：公开渠道定时抓取
  • 宏观/海外/ETF：公开 API 与交易所披露数据

3.2 数据新鲜度门控

  • 每条数据产物记录 update_time，前端按阈值标色（正常/陈旧/失效）。
  • 盘后算法链执行前校验交易日历，避免非交易日覆盖有效数据。
  • 候选池/CRDS/最终推荐等核心产物设有产出闸门，16:30 前仅警告、不判失败。

3.3 退市/异常数据护栏（2026-09-01 加固）

  • 主护栏：单轮退市数量或口径塌缩异常时，主动清空污染库，拒绝写入。
  • 下游护栏：源数据超过合理上限时，拒绝重建输出，防止已下架卡误判。
  • 所有生成脚本每轮从 main 最新拉取，确保护障策略永不回退。

🔄四、从数据到页面的流转

主站采用"数据产物注入 + 前端渲染"架构：

  1. 执行机按时间表跑算法/抓取任务，生成结构化产物。
  2. 产物经校验后提交到仓库，成为前端可直接读取的全局数据。
  3. index.html 按模块注入对应数据，纯前端渲染卡片。
  4. GitHub Pages 自动部署，全球 CDN 分发。

本页为静态说明页，不参与上述数据流转；因此即使主站数据卡空，本页仍可正常访问。
