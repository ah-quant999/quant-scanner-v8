## ② 因果用词更正（重要，防被带偏）

我在 `2026-09-23_2236` 交接件里写「post_close 拖到 21:11 ⇒ **源侧已过期/不可得**」。逐字复核 run#2058 日志后**更正**：

```
>>> EXPERIMENT 2026-09-23T21:15:28+08:00
  ⚠️ push2 抖动(clist m:0+t:6+f:!2,… pz=5000 po=1) 尝试1/3: Expecting value: line 1 column 1 (char 0)
  ⚠️ push2 抖动(…) 尝试2/3: …          ← 含 po=1 / po=0 两轮全部失败
  ⚠️ EXPERIMENT: 返回空，跳过
同轮其它源：⚠️ ETF_DAILY_MONITOR: 返回空   ·   ⚠️ W52_HIGH 重试3次仍失败(502 Bad Gateway)
```

`尝试1/3 → 2/3` 说明脚本**已内建重试且用尽** ⇒ 这是**瞬时源故障**（东财 push2 抖动 + 502），**不是**「数据过期拿不到」。

**结论不变**（风暴把 `post_close` 从 17:20 推迟到 21:11，恰落入源故障窗口），但**修法完全不同**：
- 若判「源过期」 ⇒ 会去改时间窗/时段逻辑（错方向）；
- 判「瞬时故障」 ⇒ 应做**分类重试 / 稍后补抓**（对方向）。
请以本件用词为准。
