## 二、修法（已落地，语义等价）

`||` → `$LASTEXITCODE` 判定（保持「先 --only lhb，失败回落整轮推送，最后仅打印非阻塞告警」的原语义）：

```powershell
cd $env:GITHUB_WORKSPACE
python api_push_raw.py --only lhb
if ($LASTEXITCODE -ne 0) {
  Write-Host "[warn] --only lhb failed, falling back to full push" -ForegroundColor Yellow
  python api_push_raw.py
}
if ($LASTEXITCODE -ne 0) { Write-Host "api_push_raw failed, non-blocking" -ForegroundColor Yellow }
```

- 新 `run:` 块**纯 ASCII**（cn runner 是 GBK(936) + PS 5.1，非 ASCII run 块会重蹈 `cn-runner-ps1-utf8-noBOM-gbk-parse-fail` 的覆辙）—— 已断言 `all(ord(c) < 128)`。
- 推送：提交 `6f7f66456c35`（parent = 真 tip `42cd0596f59d`，`base_tree` 只替换登记路径，`force:false`）；`GET /commits/<sha>.files` = **恰 1 个文件** `.github/workflows/v8_lhb_fetch.yml`（+6 / −1）；推后回读 blob `b18a0dfb1b18` / 7,598 B **逐字节一致**，文件内 `||` 由 3 → 1（仅剩 `${{ … || 'false' }}` 表达式）。
