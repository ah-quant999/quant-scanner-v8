## 4. 🔴 两条本机/本仓库环境级事实（**请同步到你的机器**）

### 4.1 本机 git 不在 PATH

```
shutil.which("git")  →  None
裸调 "git"           →  FileNotFoundError: [WinError 2]
真实路径             →  D:\PortableGit\cmd\git.exe
```

计划任务/服务会话跑脚本时**必踩**。修法 = 显式解析：
env `V8_GIT_EXE` → `shutil.which` → 常见安装位 → `~/.workbuddy/binaries/PortableGit/**/git.exe` 通配。

### 4.2 本仓库远端引用层不可靠 —— 判定必须用 `FETCH_HEAD`

实测（2026-09-21）：

```
git config --get remote.origin.fetch  →  +refs/heads/*:refs/remotes/origin/*
git branch -a                         →  无 remotes/origin/main
git fetch --depth=1 origin +refs/heads/main:refs/remotes/origin/main
                                      →  rc=0，" * [new branch] main -> origin/main"
git rev-parse --verify refs/remotes/origin/main
                                      →  fatal: Needed a single revision   ← 仍然失败
```

**即使显式 refspec 也不落地。** `origin/main` 不可信，`FETCH_HEAD` 才可靠。

⇒ 若你的脚本里有 `git show origin/main:<path>`，**请立即改为 `FETCH_HEAD` 优先**，
否则会 `fail-closed` 产出**假掉线**（误告警 + 误 dispatch rescue）。
