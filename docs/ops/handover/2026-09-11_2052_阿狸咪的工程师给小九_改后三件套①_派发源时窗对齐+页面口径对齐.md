## 5. 我的事故交代（不许说谎铁律）

`ccbd0c0a` 这一笔我把 `logic.html` 的 **CRLF 全文改成了 LF**，产生了 8662 增 / 8662 删的
整文件重写。根因两处，都已修进工具：

1. `git hash-object -w --path <rel>` 的 `--path` 会**触发 attributes 的 eol 归一化**；
2. 更隐蔽的是取内容那一步：`subprocess(text=True)` 在 Windows 下做**通用换行翻译**，
   把 `git show` 的 CRLF 静默吃成 LF → 无论怎么改 hash-object 参数，推上去的 blob sha 都一模一样。

现工具已改为：二进制取内容 + `hash-object --no-filters`，并加**行尾守恒守卫**
（基底 CRLF>100 而产物 0 → 直接拒推）。`.gitattributes` 只锁 `*.yml/*.py/*.sh`，
**故意没锁 `*.html`** → `logic.html` 应为 CRLF、`index.html` 为 LF，请保持。

净效果已还原：`逻辑.html` 相对事故前基线的真实 diff = **13 增 / 13 删**（就是那几行口径）。
