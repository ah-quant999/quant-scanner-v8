# 通达信选股公式（动量三件套）

> 2026-08-16 按主人选股方法论原话落地。对应「个股动量」选股体系的三大分类：反弹 / 强势股 / 加速突破。
> 每套公式都内置**标准 / 严苛 / 放宽**三个输出，行情好坏按需切换——这是主人方法论里"有时候条件可以放宽，有时候需要严苛"的落点。

## 安装（通达信）

1. 打开通达信 → 菜单 **功能 → 公式系统 → 公式管理器**（或快捷键 Ctrl+F）
2. 左侧选 **条件选股公式**（或"选股公式"）→ 新建
3. 公式名填 `JF_反弹选股` / `JF_强势股选股` / `JF_加速突破选股`（见各文件首行）
4. 把对应 `.txt` 内容整体粘贴进编辑区 → 确定
5. 使用：**功能 → 选股器 → 条件选股**，勾选对应公式，执行选股

## 三个公式怎么用

| 公式 | 适用场景 | 关键条件 |
|---|---|---|
| **JF_反弹选股** | 弱市/超跌反弹 | MACD零轴下 + 绿柱缩短/拐头/金叉 + ROE>0 + 超跌5日线 + 波动大 + 量不萎缩；含底背离加分输出 |
| **JF_强势股选股** | 正常市趋势股 | MACD零轴以上 + 5/10/20多头 + 回踩金叉 + 量能 + ROE>0 |
| **JF_加速突破选股** | 行情好加速段 | 强势条件 + 突破N日新高 + 连续放量 + 涨幅≥5% |

## 输出切换（行情好放宽 / 行情差严苛）

每个公式都有 3 个输出（选股结果里分别勾选）：

- **行情好（普涨，选出来太多）** → 勾「严苛」版：提高成交额门槛、加涨幅/突破要求
- **正常** → 勾「标准」版
- **行情差（选不出来）** → 勾「放宽」版：降低成交额门槛、去掉次要条件

另外可直接改文件顶部 `成交额门槛` 参数（默认：反弹10亿 / 强势20亿 / 加速30亿），按盘面微调。

## 关键口径（对齐主人方法论原话）

- **底背离 = 胜率加倍**：反弹公式输出3「底背离反弹」= 价格创20日新低 但 MACD柱未同步新低，单独选出来重点跟踪
- **超跌反弹看5日线、波动要大**：`CLOSE < MA5×(1-5%)` + 10日振幅≥12%
- **反弹强一点就是均线拐头**：绿柱缩短/拐头/金叉 三选一（主人口径"等待绿柱缩短、拐头、金叉"）
- **强势股回踩金叉**：先死叉再金叉（回踩窗口15日内）
- **加速要突破+量能持续放大+涨幅5%以上**

## 注意事项

- `FINANCE(33)` 为通达信"净资产收益率"字段，如你的版本取不到，改为 `FINANCE(35)` 或 `FINANCE(40)`（各版本财务字段索引略有差异，可在公式管理器里试算看数值合理性）
- 选股结果是"当日收盘后截面"，适合**盘后选、次日观察**，与动量卡跟踪节奏一致
- 每次选股结果（日期+代码清单）建议截图/导出发我，我录入「暂未上架」跟踪对照

> 口径：2026-06-08~08-07 逐日截面命中 → 持有5个交易日；未加成交额门槛（K线 amount 不全）。样本仅为 OCR 选股相关 360 只，非全市场。

|---|---|---|---|---|
| **反弹**（MACD零轴下+绿柱缩短/拐头/金叉+量不萎缩） | 1015 | **66.2%** | **+3.55%** | ✅ 与 OCR「超跌反弹」标签实测 60.3% 互相印证，方法论落地有效 |

**要点**：反弹类在弱市/超跌环境选股逻辑最稳健（66%胜率 vs 基线42%）；强势/加速类在 OCR 小池子里样本不足，但正是通「强势股」主口径的用途——等全市场日K接入后可完整验证。
