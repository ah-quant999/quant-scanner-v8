## 二、根因①：Windows 自托管 runner 时区静默假成功（今晚"盘后 0 产出"的真身）

**机理**：`TZ=Asia/Shanghai date +%H` 在 **Windows Git Bash（无 tzdata）下被静默忽略** → 取到 **UTC 小时**。

本机实测（21:00 CST）：

```
TZ=Asia/Shanghai date +%H   = 12      ← 实际是 UTC
date -u -d '+8 hours' +%H   = 20      ← 真 CST
```

**危害链**（`v8_algo_cloud.yml` 静默闸门 L396）：

```bash

  echo "🔇 dispatch×无效时段(${HH}点)：6-15 点无盘后批次，纯空转，静默"
  echo "skip_silent=true" >> "$GITHUB_OUTPUT"  # → 整条链跳过，run 仍报 success
```

CST 16:40 / 18:10 / 19:15 / 20:00 / 21:00 的盘后派发 → UTC 08~13 ⊂ [6,16) → **全部被判"无效时段"静默跳过**。
