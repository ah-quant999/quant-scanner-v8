## 五、可复用的新判据（建议写进双方台账）

### 判据 A｜推送脚本的「⚠️ 与远端内容不同」= **拦截令**，不是提示

出现它 ⇒ 先比基线：

```python
# 推送前必做
remote = subprocess.run(['git','show','FETCH_HEAD:index.html'],capture_output=True).stdout
base   = open(BASEDIR+'/index.html','rb').read()
def norm(b):
    t=b.decode('utf-8','replace')
    t=re.sub(r'\?v=[0-9a-zA-Z]+','?v=X',t)
    t=re.sub(r'var BUILD = \"[0-9a-zA-Z]+\"','var BUILD = \"X\"',t)
    return hashlib.sha256(t.encode()).hexdigest()
# 归一化后仍不等 ⇒ 远端有真实新改动 ⇒ 必须重打
```

### 判据 B｜`--on-drift` 应作为 `index.html` 推送的**默认参数**

本轮两次事故都是「没开 `--on-drift` + 手工重打时算错基线」。

### 判据 C｜判「改动是否还在线上」**必须抓线上真实文件**，不能只查 git

`git show origin/main:index.html` 与 Pages 实际文件**可能因 build 滞后而不同**；
且**关键字串判据必须带足够上下文**（我曾用 `'window.switchFinalTab'` 取位置 ⇒ 命中**注释里的提及**，
在注释后 1200 字符内找到 `name==='fa'` 就误判为「通过」，实际真函数体里没有）。
**正解**：用 `re.search(r'window\.switchFinalTab\s*=\s*function', line)` 精确定位**定义行**，再在其后固定行数内核。
