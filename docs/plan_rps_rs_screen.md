# 改造方案：个股相对强度门禁（RPS + RS + 年线）接入 v8

> 来源：《RPS+RS+200/250 个股量化筛选》（公众号「小西 西湖区的孩纸」2024-01-24）
> 目标：补上 v8 缺失的「自下而上·个股相对强度」半场，与已有「板块 RPS（自上而下）」互验。

---

## 一、现状核查（已实测，非推测）

| 能力 | v8 现状 | 证据 |
|---|---|---|
| 板块级 RPS（自上而下） | ✅ 已有 | `algorithms/fetch_sector_rs.py` + `out/sector_rs.json`（板块 vs 大盘 5d/20d 相对强度、领涨/抗跌排名）；黄金池「板块龙头」源 |

## 二、方案设计（三层，对应文章三层过滤）

### 模块 1：`algorithms/calc_stock_rps.py`（新增）
- **输入**：复用 v8 现有 universe（与 `scan_result.json` / 基本面 universe 同池，约 5537 只），不重新拉全市场。
- **计算每只票**：
  - `ret50/120/250` = 近 N 日收盘价收益率
  - `rps50/120/250` = 该收益率在 universe 内的百分位 ×10（对齐通达信 0~100 口径）
  - `rs`（曼斯菲尔德）= `(C/INDEXC)` 相对其 N 日均值的偏离 ×100，`INDEXC` 取沪深300 日线；筛选要求 `rs > 0`
  - `above_ma250` = `C > MA(C,250)`（第二阶段门禁）；同算 `above_ma200`
- **输出**：`raw_data/stock_rps.json` → `{code:{rps50,rps120,rps250,rps_max,rs,above_ma250,above_ma200,calc_date}}`
- **K 线来源**：优先 `_query_kline_em`（东方财富，已有），批量并发；指数日线同源。

### 模块 2：接入候选池 / 驾驶舱评分（轻改造，不破坏现有）
在 `build_candidate_pool.py` 与 `gen_cockpit_tier_recommend.py` 计算时加载 `stock_rps.json`：
- **新增源标签「📈 相对强度」**：满足 `rps_max >= N`（默认 90）且 `rs > 0` 且 `above_ma250` 的票打标，与现有「三重共识 / 四量终极 / 大牛股猎手 / 板块龙头」等并列作为共振源。
- **A 档（拿住别动）硬性门禁**：要求 `above_ma250` + `rs > 0`（趋势牛股必备，文章核心）；B 档（埋伏）可放宽但加 RPS 加分。
- **综合分**：在现有 `total_score` 基础上 + 相对强度分（`rps_max/10` + 年线权重）。

### 模块 3：前端展示（`index.html` 轻改）
- 个股查询卡新增「相对强度」段：RPS50/120/250 三色分 + RS 值 + 年线状态（站上/跌破）。
- 候选池命中标签增加「📈 相对强度」源；Top 推荐卡加 RPS 徽标。

## 三、核心价值：与板块 RPS 互验（文章原话"成年人两个方法都要"）
- **双强确认**：个股 RPS 强 **且** 所属板块 RPS 强（`fetch_sector_rs.json`）→ 共振加分，优先进 Top。
- **个股强 / 板块弱** → 降权（可能是独立行情/妖股），按风险偏好处理。
- 这正好把文章「自上而下 + 自下而上互相验证」落进 v8 现有双轨（板块 RPS 已有，本次补个股 RPS）。

---

## 四、落地步骤（顺序）
1. **`calc_stock_rps.py` + 单测**：先在 ~350 活跃池跑通，核对 RPS/RS/年线数值合理。
2. **接 `gen_cockpit_tier_recommend` 打分/标签**：仅加分支，不改现有源逻辑。
3. **UI 相对强度段**：个股查询卡 + 候选池标签。
4. **（可选）扩到全 5537 universe** 做全市场 RPS 排名（数据源已覆盖）。
5. **加 guard**：缺失兜底 + 字段校验，防数据缺失撑爆前端（沿用 `guard_index_sections.py` 思路）。

---

## 五、风险与成本（诚实提示）
- **数据量**：~5537 只 × 250 日 K 线。东方财富批量拉取需控制并发 + 本地缓存（可复用 `volatility_cache.json` 思路，按 code 缓存，每日增量更新）。
- **口径差异**：v8 用「收益率百分位」近似通达信 `EXTDATA_USER` RPS，足够筛选用途，会在注释标明。
- **指数源**：沪深300 日线（东财同源可取）。
- **不破坏现有**：全程新增源/分支，不删不改现有源逻辑；可一键回退（不接该源即可）。
