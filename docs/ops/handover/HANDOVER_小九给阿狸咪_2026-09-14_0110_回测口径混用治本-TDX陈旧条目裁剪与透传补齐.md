## 一、这次修了什么（一句话）

上一批给 TDX 加了「口径版本号」让**旧明细会被重算**；这次补上它的**另一半**——那些**已经掉出回测宇宙、永远不会被重算**的历史条目，此前会被当作有效样本**永久计入头条胜率**，是「口径混用」的漏网口子。已按版本号裁剪，并把审计字段打通到前端。

## 二、根因（证据链，可复核）

`algorithms/backtest_tdx.py` 是**明细级断点续跑**结构：

```
existing      = json.load(OUT)              # 直接继承整份旧产物
stock_results = existing.get("stocks", {})  # ← 从不修剪
for key in gp_stocks:                        # 只遍历「本轮宇宙」
    if key in stock_results and 口径版本一致: continue   # 跳过
...
for key, sr in stock_results.items():        # ← 汇总遍历【全部】条目
```

⇒ 汇总遍历的是 `stock_results` **全集**，而循环只访问**本轮宇宙**。两者不等价时，
**掉出宇宙的历史条目既不会被重算、也不会被剔除**，以旧口径（信号日收盘买入）永久污染胜率。

**实测证据**（远端 `8ddaff83` 产物的逐条比对）：

| 分类 | 条数 | 与上一版逐字节对比 |
|---|---|---|
| v2 口径（本轮重算） | 170 | 100% 有变化 ✅ |
| 数据不足（error） | 60 | 58 条逐字相同（确定性输出，正常） |
| **旧口径遗留** | **66** | **66/66 逐字节完全相同 ⇒ 本轮从未被遍历** |

- 66 只中 48 只**不在本轮宇宙内**（确定无法被重算）；`market` 字段仍是旧格式 `sh`/`sz`，与当前宇宙的 `沪市`/`深市` 不同源。
- 污染量级：`trend_up` 的 T+5 胜率虚高 **+0.2pp**、均收虚高 **+0.20pp**（各信号 ≤0.5pp，量不大但**性质是混口径**，触犯「code 行为一致，禁止某模块特立独行」铁律）。
