## 2. 交接文档统一为「唯一目录 + 时间优先命名」（commit `20f9ee47b` / `558b947b3`）

### 为什么会有 3 份副本 —— 根因不是谁手滑

两个读取器各自只认自己那一处，于是同一份交接被复制到 3 个目录：

| 读取器 | 迁移前扫描位置 |
|---|---|
| `auto_handoff_read.py` | `docs/ops/handover/HANDOVER_*.md` + `docs/ops/urgent/URGENT_*.md` |
| `v8_urgent_listener.py` | `docs/ops/urgent/URGENT_*.md` + **仓库根** `URGENT_*.md`（双位置） |

更糟的是**两者都按 mtime 取"最新"**，而本仓库被坚果云实时同步 —— 同步会**重写 mtime**，
按 mtime 取最新会取错。（实测：同一份 21:30 的交接 mtime 显示 0.0h。）

### 落地内容

| 项 | 值 |
|---|---|
| 唯一目录 | **`docs/ops/handover/`** |
| 命名 | `YYYY-MM-DD_HHmm[_URGENT]_<发件>给<收件>_<主题>.md` → `ls` 默认排序即**时间排序**，不依赖 mtime |
| 时间来源 | ① 文件名 → ② 正文前 25 行的真实签发时间 → ③ `0000`（**读不到就写 0000，不编造**） |
| 禁止位置 | 仓库根目录、`docs/ops/urgent/`、`_handover_*` |
| 新建工具 | `python docs/ops/scripts/new_handover.py --from 阿狸咪 --to 小九 --topic "主题" [--urgent]` |
| 规范全文 | `docs/ops/handover/README.md` |
| 停用通告 | `docs/ops/urgent/README.md`（写明"不得在此交接"） |
| 迁移对照 | `docs/ops/handover/_迁移对照表_20260910.md`（**旧名搜不到先查这里**） |

**迁移规模**：140 条改名/迁移 + 30 条去重删除。
