③ 调度韧性设计

双保险调度：云端 4 workflow 原生 cron 定时 + 本机发令枪每 15 分兜底 dispatch（互为备份）。发令枪跑在本机，不受 GitHub Actions 禁用影响。
发令枪 4 档：每小时 :00/:15/:30/:45 各一发令枪，覆盖 09:00–19:00 全交易时段，云端任一档位沉默即被唤起。
Concurrency 锁：所有 workflow 按调度档位分组互锁（同一档位串行，不同档位不互杀），根除大范围 cancelled。
容错设计：除"抽页/同步/同源校验"等严格步骤外，所有数据抓取/计算步骤均设续跑保护，单个步骤超时/失败不会使整个 job 失效、不累积禁用性失败计数。
新鲜度闸门：部署前对比线上数据时间戳，若本地不比线上新则跳过部署（但不判 job failure）。
冲突检测：每次部署前扫描 origin/main 的 data/ 目录是否有 git 冲突标记残留，有则阻断部署。
兜底层级：云端原生 cron → 发令枪 API dispatch → 双机定时(08:45/每:40/16:31/19:30) → 19:30 守卫部署。任一层失效，下一层 30 分钟内自动顶上。
云端掉线兜底（silent_failover）：当云端心跳(hb_cloud.json)沉默 >30min，阿狸咪/小九自动激活本机盘中 5 + 盘后 1 默认 PAUSED 任务做补跑，云端恢复后自动 PAUSED 回去。
小九掉线接管（peer_failover）（⚠️ 2026-07-23 新增）：阿狸咪每 30 分读取小九心跳(hb_xiaojiu.json)，若小九沉默 >90min（停电/断网），自动激活本机 PAUSED 救火任务（close_p1/p2/deploy/backup/pre_market）补跑；小九恢复后自动交还。

📊 CRDS 逆势龙头评分（暂未上架区）

CRDS = AF × min(VR, 3) × (1 + 逆势板占比)
AF = 逆势强度（个股涨跌 / |大盘涨跌|）
VR = 量价比（涨停日成交额 / 20日均成交额，封顶3倍）
逆势板占比 = 大跌日涨停数 / 10日内总涨停数
归一化后 CRDS 评分范围 0~100，三项条件全满足的进入"精选级"。

📌 结论
• 条件②只有在大盘跌幅 ≤ -1.5% 的交易日才会被触发；其余三种天气下条件②必然为 false，精选级无数据。
• 如果今天大盘只跌 -0.8% 或涨 +0.5% → 进阶级（条件①+③）正常出，但它本质就是"10日内有2板的放量股"，等同于你系统里既有的短期强势动量，不是新信息。
• CRDS 是"恐慌刀"：日常晴天用普通扫描/多维共振即可；只有市场单日暴跌 ≥-2% 或连续阴跌时，CRDS 才能从 73% 的下跌股里捞出 2% 逆势封板的金子。
• 大盘连续阴跌 → CRDS 累积信号最强（一次 2 板 + 一次逆势 = 双重确认的强势股）。

ZT:=C/REF(C,1)>=1.095 AND C=H; IDN:=(INDEXC-REF(INDEXC,1))/REF(INDEXC,1)*100<=-1.5; VR:=AMO/MA(AMO,20); VR3:=MA(AMO,3)/MA(AMO,20); ZCNT:=COUNT(ZT,10); ZDOWN:=COUNT(ZT AND IDN,10); VRMAX:=HHV(VR,10); AFMAX:=HHV(IF(ZT AND IDN,(C/REF(C,1)-1)*100/ABS((INDEXC/REF(INDEXC,1)-1)*100),0),10); CRDS:=(AFMAX*MIN(VRMAX,3)*(1+ZDOWN/MAX(ZCNT,1)))/3*10; {均衡版} SEL:ZCNT>=2 AND ZDOWN>=1 AND VRMAX>=2.0 AND VR3>=1.5 AND CRDS>=15;
分级：精选级（三项全满足）/ 进阶级（两项）/ 关注级（仅量能确认）。

📉 4.1 波动率观测（驾驶舱右卡）

数据源：指数日 K 公开数据（多源冗余）。
覆盖指数（5 个）：上证指数 / 沪深 300 / 创业板指 / 中证 500 / 中证 1000。
r_t = ln(C_t / C_{t-1}) 对数日收益
vol_20d(t) = std(r_{t-19..t}) × √252 × 100 20 日年化已实现波动率(%)
vol_5d(t) = std(r_{t-4..t}) × √252 × 100 5 日年化波动率(%)
vol_trend% = (vol_20d(t) - vol_20d(t-5)) / vol_20d(t-5) × 100 趋势(正=升,负=收敛)
vol_pctile = 当前 vol_20d 在近 120 日滚动分位(0~100)
ret_5d / ret_20d / ret_60d = 区间累计收益(%)
复合大盘波动信号（4 态判定）：
20 日收益 5 日波动趋势 信号 颜色 含义
≥ 0< 0stabilize 企稳回升🟢 绿价稳 + 波动收敛，恐慌释放后修复
< 0< 0grind 阴跌磨底🟡 琥珀价未止跌但杀跌动能衰减
≥ 0≥ 0rebound_diverge 反弹分歧🔵 蓝价反弹但波动仍在升，假摔/分歧风险
< 0≥ 0panic 恐慌下行🔴 红价跌 + 波动上升，恐慌加速
复合值：5 指数 vol_20d 取简单平均 → composite.avg_vol_20d；短端（5 日）同理。
vol_short_vs_long_pct = (avg_vol_5d − avg_vol_20d) / avg_vol_20d × 100，正值=短期波动高于长期中枢，市场恐慌未止。
驾驶舱位置：顶部双卡布局——左卡=宏观环境（绿钉·可操作），右卡（#cockpitVolSlot）=波动率观测。JS 在渲染 cockpit 时把 #volatilityCard 从 DOM 原位移入 cockpitVolSlot。

🧬 4.2 CRDS 逆势龙头评分（管理员可见·实验区）

数据源：涨停板公开数据 + 上证指数日 K + 龙虎榜席位数。
触发条件：上证单日跌超 1.5%（恐慌暴跌日）→ 筛选当日逆势涨停/抗跌股。
CRDS_score =
  + 逆势涨停(RL1板) +3
  + 首板(非一字涨停) +1
  + MACD 5min 金叉 +1
  + 龙虎榜净买入 > 0 +1
  + 机构席位净买(1家+1, 2家+2, ≥4家+3) +1 ~ +3
  + 板块跟风效应(同板块≥2涨停) +1
  + 流通市值<100亿/成交<10亿(小盘) +1
  + 相对大盘强度(个股涨幅-大盘涨幅) > 5% +1
max_score ≈ 11
分级：CRDS ≥ 6 → 强逆势信号，重点跟踪；CRDS ≥ 8 → 极强（概率最高）。
显示位置：管理员可见的「🧪 实验选股调试专区」→ CRDS 逆势龙头卡，盘中刷新更新。
使用提示：日常晴天用普通扫描/多维共振即可；只有市场单日暴跌 ≥-2% 或连续阴跌时，CRDS 才能从 73% 下跌股里捞出 2% 逆势封板的金子。

🚀 4.3 打新速览（IPO 评分）

数据源：新股日历公开数据。盘前 08:45/09:25 两次采集更新。
IPO_score(0~100) =
  + 市盈率(PE)评价 -20 ~ +20（低于行业均值加分）
  + 募资/超募比例 -10 ~ +10（超募扣分）
  + 发行价格 -15 ~ +10（高价扣分）
  + 主业赛道(科创板/创业板加分) 0 ~ +15
  + 营收增长率(近3年) -10 ~ +15
  + 净利润增长率 -10 ~ +15
  + 总市值与流动性估值 -15 ~ +10
  + 承销商历史胜率 -5 ~ +5
推荐分级：score ≥ 75 → 积极申购 ｜ 60~74 → 建议申购 ｜ 50~59 → 谨慎参与 ｜ < 50 → 建议放弃。

💰 4.6 推荐持仓与止盈止损

仓位基于共振评分（80+→高/70~79→中/<70→低）。
day_risk = ATR_60 / close 近 60 日振幅中位数 ×1.5stdev / 收盘
止损 = 入场价 × (1 − day_risk × 2.0)
止盈 1 = 入场价 × (1 + day_risk)
止盈 2 = 入场价 × (1 + day_risk × 2.0)
止盈 3 = 入场价 × (1 + day_risk × 2.5)
持仓时间 = f(信号数, CRDS, 板块RS) 1~60 天区间
仓位矩阵：评分 ≥ 80 = 高仓位（满仓上限 100%），70~79 = 中（上限 70%），< 70 = 低（上限 30%）。
数据源：K线公开数据。
风险控制：所有推荐股都附带 day_risk × 2 止损，单股最大损失不超过总仓位 2%。
