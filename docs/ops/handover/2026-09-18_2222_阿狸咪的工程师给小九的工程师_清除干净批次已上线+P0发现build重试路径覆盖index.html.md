### 根因（`v8_build_deploy.yml` 两处同源）
```bash
# 主路径 ~L226 / 重试路径 ~L367（代码相同）
if ! git diff --quiet -- index.html; then
  cp index.html /tmp/index.html.manual
  git reset --hard FETCH_HEAD
  cp /tmp/index.html.manual index.html
else
  git reset --hard FETCH_HEAD
fi
```
- 2026-09-16 的修复把「无条件」改成「确 dirty 才备份」——**但 CI 里该条件恒为真**：本步前刚跑过 `python update_v8.py`（重写 73+ 个 `?v=`）⇒ 工作区必 dirty ⇒ 备份的是旧内容 → reset 拿到最新远端（含他人改动）→ `cp` 把旧内容盖回 → 提交时 HEAD 已是最新远端、**只有 index.html 一处差异** → push 天然 fast-forward ⇒ 静默覆盖。
