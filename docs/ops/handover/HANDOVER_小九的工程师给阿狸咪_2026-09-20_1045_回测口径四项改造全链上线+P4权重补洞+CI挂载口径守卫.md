## 2. 本轮新增改动（阿狸咪建议 4 项之外的第 5、6、7 项）

### 2.1 【新·补洞】P4 权重路径原只读 edge10

**位置**：`algorithms/generate_top10.py`，原 L664–L706 一带。

**问题**：信号层（jinzuan/chan/jigou/trend）上轮已切 `excess5`，但 **P4 因子层（`p4_lowvol45/55`、`p4_resid5/10`）仍全部读 `edge10`**：
```python
_rec = {"edge10": _v.get("edge10", 0) or 0,
        "edge5":  _v.get("edge5", 0) or 0,
        "n":      _v.get("n_on10", 0) or 0}
```
⇒ 4 个 p4 因子的权重**仍建立在 T+10 β 假象之上**。

**改法**（回退链 `excess5 → edge5 → edge10`，兼容旧产物）：
```python
_e10 = _v.get("excess5")
if _e10 is None: _e10 = _v.get("edge5")
if _e10 is None: _e10 = _v.get("edge10", 0)
```
同时把 `_p4_effective_edge()` 与 `p4_score_for()` 一并切新口径。

### 2.2 【新】P4 防噪闸门从「T5/T10 同号」改「IS/OOS 同号」

原闸门 `if e5 is not None and (e5 > 0) != (e10 > 0): return 0`。
**同病的理由**：T5/T10 均为**绝对收益差**，同号不构成独立证据（都被同一段 β 抬高）。
⇒ 实测四信号该判据**恒为 True，从未拦下任何东西**。

新判据改 **IS/OOS 同号**（真·样本外一致性），与信号层**完全同口径，禁特立独行**。
缺字段时放行（防旧产物静默清零）。

### 2.3 【新】CI 挂载口径守卫 `[9/9]`

**位置**：`.github/scripts/pre_deploy_audit.py`（8 项 → **9 项**）。

## 6. 本轮踩坑记录（供后续复用）

1. **`pre_deploy_audit.py` 放临时目录会退化成盘根扫描**
   `ROOT = Path(__file__).resolve().parent.parent.parent` ⇒ 放 `<tmp>/pre_deploy_audit.py` 时 ROOT 退到 `E:\`，
   `check_html_refs` 去扫整个盘 ⇒ 120s 超时（**假阳性**）。
   ⇒ 测该脚本须按真实深度 `<tmp>/repo/.github/scripts/` 搭沙箱。

2. **`guard_backtest_caliber.py --json` 的 `info` 是「字符串列表」不是 dict**
   ⇒ 消费侧需自行 `partition("=")` 抽字段（本处已按此实现）。

3. **审计项行首图标 ≠ 档位标记**
   `✅/❌ [9/9] xxx:` 的首个图标是**审计项 pass/fail 列**；档位在消息体里。

4. **本机 Bash shim 不稳**（`dirname`/`cd`/`head`/`grep` 间歇 `command not found`）⇒ 全程 PowerShell + Python 落盘读结果。

5. **`regime_filter` 会触发 baostock 登录**（stdout 出现 `login success!`）⇒ 本机跑批须留足时间，勿误判挂死。
