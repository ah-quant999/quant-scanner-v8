```

LEVEL_HEALED   = "healed"    # 已自愈确认 —— 永久不发（自愈成功本就无需主人出面）
```

`send_alert()` 现在的三道串联闸门：
```

  ↓

  ↓
_dedup_check(...)      ← 🆕 同类冷却 6h：同一问题只发一封
  ↓
真正 SMTP 发送
```

`audit_alert()` 的审核规则（逐条）：
| # | 规则 | 作用 |
|---|---|---|
| ① | `progress`/`healed` 级 ⇒ 拦截 | 自愈成功/进度汇报不打扰主人 |
| ② | 主题含「完成/已修复/回执/汇报/进度/清场核查/心跳修复/N/N」等**报喜话术** ⇒ 拦截 | 挡住换皮成 infra 的进度播报 |
| ③ | 正文未含「请/需/无法自动/自愈失败/异常/离线/5xx/超时/缺失」等**动作或异常线索** ⇒ 拦截 | 无信息量的自动回执不发 |
| ④ | 正文 < 20 字 ⇒ 拦截 | 同上 |

`_dedup_check()`：剥离时间戳后取主题指纹，**6 小时内同一指纹只发一封**（`V8_ALERT_DEDUP_SEC` 可调）。

## 三、主人新令二：概念资金热力图改版（**待我方盘中后做，先同步口径**）

### 诊断（已勘查完两处渲染器）
| | 行业树图（要学的） | 概念资金热力图（要改的） |
|---|---|---|
| 面积口径 | `area=sqrt(|pct_day|)/sqrt(maxVal)` | `area=sqrt(|net|)/maxArea` |
| 字号档 | `titleFz=px>=110?15:(px>=75?13:12)` | `titleFz=px>110?13:(px>80?12:(px>55?11:10))` |
| 名称 | **全写出** | **大量省略号**（`white-space:nowrap`+`ellipsis`+格子小） |
| 行数 | 多行、格子高 | 两行、格子矮 |

### 🔴 面积口径勘查结论：**当前算法已正确，无需改口径**（曾误判，此处更正）

概念卡现状：`maxArea = sqrt(|net[0]|)` → `area = sqrt(|net|)/maxArea` → `px = max(44, area*130)`
行业树图：`maxVal = |pct[0]|` → `area = sqrt(|pct|)/sqrt(maxVal)` → `px = max(44, area*130)`
**两者数学同构**（都是 `px ∝ √值` ⇒ `px² ∝ 值` ⇒ **面积 ∝ 数值**）。

逐格实测 `px²/net` **恒等于 ≈289**（289.5 / 290.2 / 287.3 … 288.6）⇒ **面积已严格正比于金额**。
⇒ **主人说的「按金额算面积比例」当前已满足**，本次改版**只调视觉，不动面积公式**。
