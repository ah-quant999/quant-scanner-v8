### 4.2 数据内容 —— **停在 2026-09-15，已 8 天 ✗**

- 56 行 `trade_date` **全部** = `2026-09-15`（无一例外，已逐行统计）
- 源笔记自述 `source_title` = 「强势股跟踪日报 **2026-09-15**」，`wiki_latest` 同
- 产物字段：`data_date=2026-09-15`、`stale_days=8`、`source_stale=**false**`

⇒ **头部「已更新 于 今日 21:03」是「抓取时刻」，不是数据新鲜度**。
而 `fetch_ima_strong_stock.py:923-927` 把 wiki 源的 `source_stale` **设计成恒 false**（理由：wiki 取到的就是最新一篇，不因「距今 N 天」报停更，避免诬告），于是：

- 前端红胶囊判据 `if(D.source_stale && D.data_date)` **永不成立**；
- `data_date` 又**从来没被渲染**（全站只有这一处判据引用它）⇒ 主人**看不到任何**「数据其实是 8 天前的」提示 = 假新鲜。

### 4.3 本次修法（只补前端，**不动生产者口径**）

新增「**📅 数据日 YYYY-MM-DD**」**常显**胶囊，与「已更新（抓取时刻）」并列：

- `stale_days > 0` → 黄（`#fbbf24`）；`≥ 5` → 红（`#ef5350`）；当天 → 灰（`#94a3b8`）
- 判据全部取产物字段（`D.data_date` / `D.stale_days` / `D.source_title`），**不臆测、不改数**
- 与 `source_stale` 分支互斥（`&& !D.source_stale`），不会双胶囊
