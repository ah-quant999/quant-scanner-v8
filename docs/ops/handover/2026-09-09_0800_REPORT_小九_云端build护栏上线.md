## 五、⚠️ 上线过程中的两个坑（已根治/已记录）

**坑 1：本机有自动化定期 `git reset --hard origin/main`，工作树改动被冲掉 2 次**
- 第一次：`stash push` → `rebase` → `stash pop` 报 `refs/stash@{0} is not a valid reference`，stash list 空
- 第二次：reflog `reset: moving to origin/main`，HEAD 被拉回
- **根治**：改完立刻 `git add` + `git commit`，不让改动在工作树停留；改动被冲时从会话 diff 原文重新 Edit 应用

**坑 2：`git push` 在本机网络环境下不可靠**
- 连续报 `Connection was reset` / `Failed to connect :443` / `Could not resolve host`
- **解法**：改用 `_put_main_file.py`（Contents API 走代理），一次成功
- 配套：`git fetch <url> main` 只更新 FETCH_HEAD 不更新 origin/main 引用，rebase 要用 `git rebase FETCH_HEAD`
