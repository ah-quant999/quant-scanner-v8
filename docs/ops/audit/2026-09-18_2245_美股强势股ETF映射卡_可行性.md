## 3. 🔴 时区口径（本卡最容易做错的地方）

实测行情时间字段（22:44 北京）：

```
usAAPL   行情时间 = 2026-09-18 10:43:59   ← 美东 10:43，美股正在盘中
hk00700  行情时间 = 2026/09/18 16:08:32   ← 港股已收盘
```

| 北京时间 | 美股状态 | 对 A股/港股的意义 |
|----------|----------|-------------------|
| 21:30 – 次日 04:00 | **盘中** | 此时 A股/港股已收盘 → 只能做「**今晚关注**」前瞻 |
| 次日 04:00 – 09:30 | 已收盘 | **这才是「隔夜美股」** → A股 09:30 开盘前唯一可用的完整交易日 |
| 09:30 – 16:00（A/H 盘中） | 休市 | 页面显示的美股最新价 = **当日凌晨收盘价** |

⇒ **卡片口径必须是**：`数据日 = 美股最近一个已收盘交易日`，卡名用「**隔夜美股强势**」；**禁止**写成「实时／今日美股强势」。若加实时段，必须单独分区并显式标注「美股盘中（对 A/H 无当日传导，仅供今晚前瞻）」。

另：`premarket` 档（北京 08:25）落在美股盘前时段，此时报价接口给出的「最新价」即**上一交易日收盘价**，与「隔夜」语义天然对齐 ⇒ **该卡挂 `premarket` 单档即可**（可选补 `post_close` 给晚间读者）。**不要挂 `intraday`**——盘中抓到的仍是同一根隔夜数据，白耗抓取预算。

## 4. 🔴 映射表必须「人工策展 + 机器闸门」

### 4.1 本次实测的闸门机制与结果

用**两侧中文名一致性**做校验（US 侧东财中文名 vs HK 侧腾讯中文名，去 `-W/-SW/-S` 归一化）：

```
US 侧命中 22/24 ；HK 侧命中 24/24
名称一致 21/24
不一致 3 处：
  BABA  → 我草稿写的前缀「105」错（实为 106 NYSE），故中文名为 NULL
  ATAT  → 我草稿写的「09676」实际是【十月稻田】（亚朵不在该代码）
  VNET  → 我草稿写的「00837」实际是【谭木匠】（世纪互联不在该代码）
```

⇒ **用记忆维护映射表 = 必然出错**（我自己的 24 对草稿错了 3 对，错率 12.5%）。闸门必须内建：

1. 逐对校验 US 侧可取到 + HK 侧可取到；
2. 两侧中文名归一化后必须互相包含，**不一致 → 剔除该对 + 写入告警**（禁静默降级）；
3. 校验失败的对**不得**出现在前端卡上（宁缺勿错，符合「不许说谎」铁律）。

修正后确认的正确前缀：`ATAT=105`、`VNET=105`、`BABA=106`、`TME=106`、`NIO=106`。
