## 三、本次交付物（已入仓）

### 3.1 新增文件

```
docs/ops/scripts/disk_clean_weekly.py     跨机自适应版（29770 B，纯 LF）
```

**相对小九机本地版的唯一改动**：把 7 处写死的 `C:\Users\Administrator\...` 改为**自动探测本机用户目录**。

| 改造点 | 原写法 | 现写法 |
|---|---|---|
| 批5 四条路径 | `"C:\\Users\\Administrator\\AppData\\Local\\Temp"` 等 | `os.path.join(_HOME, "AppData", "Local", "Temp")` 等 |
| 批6 root | `r"C:\Users\Administrator\.workbuddy\projects"` | `os.path.join(_HOME, ".workbuddy", "projects")` |
| 批7 WB | `r"C:\Users\Administrator\.workbuddy"` | `os.path.join(_HOME, ".workbuddy")` |
| 批8 `_C_APPDATA` | `r"C:\Users\Administrator\AppData"` | `os.path.join(_HOME, "AppData")` |

**探测优先级**：`env USERPROFILE` → `env HOMEDRIVE+HOMEPATH` → 向上 walk → 兜底。

### 3.2 新增能力：启动横幅自动暴露 junction 真相

脚本启动时会打印：

```
  -- 本机路径探测（跨机自适应）--
     USERPROFILE = C:\Users\Administrator   [env:USERPROFILE]
     .workbuddy     REPARSE -> E:\workbuddy-data
     AppData        normal dir
  -- note: if .workbuddy is a junction, batch 6/7 free the TARGET drive, not C --
```

**为什么必须加这个**：小九机 `.workbuddy` 是 junction → `E:\workbuddy-data`，所以**批 6/7 清的其实是 E 盘，不是 C 盘**（2026-09-18 曾因此把「C 盘清理」方向搞错）。阿狸咪机是否为 junction **未知**，故脚本不替使用者判断，而是**把事实打印出来由执行者当场核对**。

### 3.3 依赖：**零第三方包**

脚本只用 `os / sys / io / time / json / stat / shutil / argparse / ctypes`，**全是标准库**。阿狸咪机只要有 Python 3 即可运行。
