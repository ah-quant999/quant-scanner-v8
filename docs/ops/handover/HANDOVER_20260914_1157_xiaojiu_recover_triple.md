## 一、四项修复（本次推送 `aee86d232` 最终内容）

### ① 符号写法统一 —— 新增 `fmtSigned()` 单一真源

**问题**：同一页卡片符号写法不一（有的 `++` 两个加号、有的完全没有 `+`）。

**根因（已实测排除误判）**：
- 实测 `CONCEPT_RANKING.js` 100 项数据全为 number 类型、负值项为 0 ⇒ **不是数据类型问题**；
- 真因是**小字号 + 缺 `white-space:nowrap`** ⇒ 符号被父级 `overflow:hidden` 挤压/裁切；
- 另**实锤**一处量级错误：`+11.78亿` 被硬切成 `+1.78亿`（十倍误差）。

**修法**：两个独立 IIFE（概念资金热力图 / 行业树图）**各注入一份** `fmtSigned(v)`——受作用域隔离无法共享，故各一份：

```js
function fmtSigned(v){
  if(v == null || isNaN(v)) return '--';
  var n = Number(v);
  var s = Math.abs(n).toFixed(2);      // 先取绝对值格式化
  return (n > 0 ? '+' : (n < 0 ? '-' : '')) + s;   // 再按符号补一次
}
```

**结构上不可能产出两个符号** ⇒ 根治 `++` 叠号。调用点：`netTxt=fmtSigned(it.net)`、涨跌幅行 `fmtSigned(pct)+'%'`，并补 `white-space:nowrap`。
