## 一、紧急修复：持仓录入匹配错误（CRITICAL）

### 问题描述
用户在 TOP3 持仓跟踪卡录入「广钢气体」(拼音 `gqqt`)，结果匹配到了**浦发银行** (sh600000)！

### 根因（经典 JS 陷阱）
`_pfFindStock()` 函数有**独立的搜索逻辑**，未接入统一搜索内核 `_uniSearch()`。

```javascript
// 用户输入 'gqqt'（纯字母）时：
var nc = normCode('gqqt');  // nc = '' （空串！）
sc.indexOf(nc) === 0;       // '688548'.indexOf('') === 0  → 永远为真！
// → 每只股票都得 3 分基础分 → 第一只碰巧命中的（浦发银行）就赢了
```

### 修复内容（commit `e25e349c8` → `51dd83f`）

| 修改 | 说明 |
|------|------|
| `_pfFindStock()` | 改为优先调用 `window._uniSearch(q, 1)` |
| fallback 守卫 | 增加 `nc` 检查：`if(nc && sc===nc)` — 空串时不走 code 匹配 |
| `doStockDiag()` fallback | 清理未定义变量引用 (`isA/ql/qc/best` → 会抛 ReferenceError) |
| 持仓录入框 | 新增下拉联想 `showPfDropdown()` / `hidePfDropdown()` |
