## 四、上线与核验

- **⚠️ 为什么是「5 文件」而不是「6 文件」**：本机 git 直连 github.com:443 不通（`Empty reply from server`），只能走 API；而经 PAT 创建**含 `.github/workflows/` 路径**的 tree 会被 GitHub 拒绝：
  ```
  HTTP 403 {"message":"Resource not accessible by personal token",
            "documentation_url":"https://docs.github.com/rest/git/trees#create-a-tree"}
  ```
  即 fine-grained PAT 缺 **Workflows 写权限**。同一 token 写**非 workflow 路径**均 201 成功、单条目 tree 亦 201 成功（已实测对照），可确认是权限而非限流或仓库保护。

  ```bash
  git apply docs/ops/patches/v8_build_deploy_index_cover_fix_20260916.patch
  ```
