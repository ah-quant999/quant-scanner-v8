## 二、改动详情

### A · P2「每日因子计算」卡：数值改动态取值

**根因（截至 2026-09-20 09:30 实测）**：卡片硬编码 **T+10 原始 edge**
（`+8.07% / +3.86% / −9.00% / −7.24%`），而源码 `algorithms/generate_top10.py`
在 2026-09-20「改动15」已把口径改为 **T+5 超额**
（`SIGNAL_EDGE_DEFAULT = {jinzuan 0.532, chan 0.759, trend -1.532, jigou -0.660}`）
⇒ **旧值量级夸大 5~10 倍**。主人对「反」的理解正确（= 命中扣分），错的是分值大小。

**🔴 关键踩坑（我第一版改错、当场修正）**：
第一版读 `window.BACKTEST_EXPECTANCY`，**该全局变量在线上不存在** ——
实测 `data/` 目录 119 个文件里**没有** `BACKTEST_EXPECTANCY.js`；
`backtest_expectancy.json` 是**算法侧运行时读本地文件**，**从不发布到 `data/`**
⇒ 浏览器侧**永远拿不到**，卡片会永久显示「口径待同步」，等于把「显示旧值」
变成「什么都不显示」。**已修正为自带硬表镜像。**

**最终实现（三级取值链）**：
1. `window.BACKTEST_EXPECTANCY.by_factor[sig_*].excess5` → 回退 `.edge5`（可达时优先）
2. `_SIG_EDGE_SRC` 硬表镜像，与 `generate_top10.py::SIGNAL_EDGE_DEFAULT` **逐字对齐**
3. 全空 ⇒ 显示「未载入」，**不编数**

分值 = `round(edge × 2.5)`，clamp ±30；每项标注取值来源（回测真值 / 源码硬表）。
note 显著标注 **「机构变红 / 上涨趋势为反向因子，edge 为负 ⇒ 命中即扣分」**。

**Node vm 沙箱三场景实测**（可复跑）：
- 无回测文件 ⇒ 硬表 `+1 / +2 / −2 / −4 分`（与源码 ×2.5 一致）
- 有回测文件 ⇒ 动态覆盖生效
- 部分字段缺失 ⇒ 逐项回退，其余落硬表

### B · P5「walk-forward 达标因子」卡：补「为什么停用」

**可否删除的答案：不能。** 三重理由：
1. **动态闸门**：`verdict=PASS` 才启用；复跑不达标即自动失效。任一因子转 PASS
   **会自动恢复计分** ⇒ 删掉 = 永久放弃这条路。
2. **判定门槛**：`IR_OOS > 0.3` **且** 年度跑赢率 ≥ 80%（8 年数据 ⇒ 需 **7 年**达标）。
   截至 2026-09-19 18:25:37 实测：**12 个候选因子无一通过**，多数倒在年度跑赢率
   （最好 `6/8 = 75%`，差 1 年）。
3. **会翻转**：同日新增一天数据即触发全历史重算。实测 `amt60` 曾连续 7 版 PASS
   （09-16 20:44 ~ 09-19 16:25），09-19 18:25 因窗口滑动（08-07→08-21）翻转为 FAIL，
   `spread_avg_pct` 从 2.0366% 腰斩到 1.049% ⇒「今天停用」≠「永久失效」。

⚠️ **遗留口径抵触（P1 待主人拍板，不阻塞）**：文档 `criteria` 写「≥4/5 年」，
但代码 `factor_walkforward.py::pass_yr = n_ok/n_y >= 0.8`（8 年 ⇒ 需 7 年）。
两者不一致，**当前门槛偏严**（若按 4/5=80% 同义，则「4 年里 4 年达标」即可，
与「8 年里 7 年」不等价）。**是否放宽到 6/8 待定 —— 需先验证是否会放进噪声。**

### C · 全市场画像卡：降格为「已否决」

**该卡是什么**：负向验证研究快照。**无生成器 / 无数据源 / 无定时任务**，

三个子口径全为负（距 60 日高 −2.13%*、偏离 60 日均线 −2.17%）⇒ **达否决条件**。

**改动**：标题改「已否决 · 全市场画像因子」+ 副标「证伪留档（永不接入推荐链）」，
