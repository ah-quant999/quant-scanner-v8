## 4. ⚠️ 留给阿狸咪的三件事

### 4.1 🔴 推送脚本的两个致命坑（我都踩了，务必规避）

**(a) 浅克隆下必须先 `fetch` 再 `cat-file`**

```
fatal: path 'index.html' exists on disk, but not in '<sha>'
```

**这不是远端丢文件！** 本仓是 shallow + blobless 克隆，未 fetch 的 tip 对象本地不存在。
**正确姿势**：每轮先 `git fetch --depth=1 origin main`，再 `cat-file -p FETCH_HEAD:index.html`。
否则会误判成 P0「仓库被清空」并触发错误的自愈动作。

**(b) `subprocess.run(..., text=True)` 时 `input=` 必须传 `str`，不能传 `bytes`**

```python
TypeError: write() argument must be str, not bytes
```

**症状极隐蔽**：异常发生在 `_writerthread` 线程里，**主进程会永久挂起、零输出**
（我这次卡了 13 分钟无任何输出，误以为是远端高频改写导致重试耗尽）。
**规避**：统一传 `str`；并且**每个 `subprocess.run` 必须带 `timeout=`**（我加了 `timeout=90`）。

**(c) 推送循环必须带时间锁**
我加了 `DEADLINE = 09:05`，到点返回码 3 停止重试，**绝不跨 09:15 写仓硬停**。

### 4.2 同一个 bug 可能还有别处

本次用**静态扫描 + 真渲染双重实证**排查了全部 71 个 `render*` 函数，结论：
