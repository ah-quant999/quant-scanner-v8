## 五、刷新范围（自动 vs 人工，红线）

| 字段 | 是否自动刷新 | 说明 |
|---|---|---|
| `series.dates` / `series.closes` | ✅ 自动 | 上证日线序列 |
| `idx[]`（5 指数 last/hi/hdate/dd） | ✅ 自动 | 沪深300/创业板指/深证成指/科创50 |
| `meta.date` / `last` / `pct` / `source` | ✅ 自动 | |
| **`marks[]`（浪型拐点 ①起~⑤高）** | ❌ **人工保留** | **脚本只原样保留，绝不重新判定**——浪型拐点是主观研判结果 |

> 🔴 **红线**：`marks` 是人工研判资产。脚本从头到尾不重判、不生成、不删除。要调浪型拐点，手工改 `data/WAVE_ELLIOTT.js` 的 `marks` 数组或改 `v8/wave_report_template.html` 文案。

## 六、幂等设计（防风暴）

- 脚本比对「新拉到的最新交易日」vs「已记录最新日」：
  - **相同**（周末/假期/已跑过）→ **跳过推送**，仅校验 + 渲染，**零写入**。
  - **不同** → 刷新 + 推送。
- `--force` 参数可强制重算并推送（仅调试用）。

## 七、防踩踏设计

- 推送走**隔离索引 raw-tree-push**（独立 `GIT_INDEX_FILE`），**不碰工作树、不碰真实索引**。
- **范围守卫**：`diff-tree` 断言改动文件**恰为 `data/WAVE_ELLIOTT.js` 一个**，否则直接 `exit 1` 拒绝推送。
- **绝不触碰 `index.html`** 热文件，与阿狸咪夜间部署无冲突。
- 禁用 force push。
