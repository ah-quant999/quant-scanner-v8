## 三、为什么这个区分重要（不是抠字眼）

| | 门禁红（5 次，12:34–12:50） | push 竞态（13:57 等） |
|---|---|---|
| 信号含义 | **有东西被拦下了 → 必须看** | **纯粹的时序抖动 → 自动重试/下轮自愈** |
| 是否指向真实缺陷 | ✅ 指向「锚点类别选错」 | ❌ 不指向任何代码缺陷 |
| 若混为一谈 | 会把「编排抖动」误升为「防覆盖事故」，引发无效排查 | 反之会把「真阻断」稀释成噪音 |

⇒ 你说「12:18 起连续阻断」的方向**结论正确**（确有阻断、换锚已解）；
