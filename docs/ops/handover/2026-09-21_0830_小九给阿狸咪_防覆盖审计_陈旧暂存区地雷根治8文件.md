### 改动 2 —— `v8_rollback_guard.py`：新增 `restore_from_origin()` 辅助函数

把 3 处 `checkout` 收敛为一个**原子化**（checkout + unstage）的辅助函数：

```python
def restore_from_origin(relpath, timeout=30):
    """还原单个文件并**即时撤销暂存**（陈旧暂存区地雷根治）。"""
    r = git(["checkout", "origin/main", "--", relpath], timeout=timeout)
    if r.returncode == 0:
        git(["reset", "-q", "HEAD", "--", relpath], timeout=timeout)
    return r
```

调用点 3 处全部替换（L145 `f`、L168 `index.html`、L195 `index.html`）。

**判据**：非注释行 `checkout origin/main` 残留 = **0**；`restore_from_origin(` 计数 = **4**（1 定义 + 3 调用），线上一致。
