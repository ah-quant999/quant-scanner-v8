🌡️市场温度计 - 说明

综合打分
0~100 = 0.3×涨跌家数比 + 0.2×量能分 + 0.2×北向分 + 0.15×涨停跌停比 + 0.15×情绪分。
temp = 0.3*ad_ratio + 0.2*vol_z + 0.2*north_z + 0.15*zt_ratio + 0.15*sentiment
分档
≥70 偏热 / ≤30 偏冷 / 30-70 中性。北向停更后北向分权重仍保留，但数据源标注停更。

🕸️六维共振雷达 - 说明

六个维度
量能 / 情绪 / 资金 / 估值 / 技术 / 外围。各维归一化到 0~100 后绘制多边形。
dims = [vol, sentiment, fund, valuation, tech, external] norm = clip((x - lo)/(hi - lo) * 100, 0, 100)
危机雷达算法
综合危机指数 = 货币×40% + 经济×35% + 全球×25%。状态分档：0-30平稳 / 30-50关注 / 50-70警惕 / 70-100危机。
指标危险分
基于近1年历史分位。越高越危险指标（SHIBOR/VIX/DXY/两融/离岸汇率）危险分=分位；越低越危险指标（期限利差/中美利差/PMI/出口/CPI/房价/铜金比/BDI/美债倒挂）危险分=100−分位。

时间窗口

价格窗口

与宏观事件重合

💰资金流口径 - 说明

板块/概念资金流

主力资金定义
超大单(≥50万股或≥100万元) + 大单(≥10万股或≥20万元) = 主力净流入。
资金流向追踪

🌍宏观观测 / 危机监测 - 说明

宏观观测
追踪四大类：货币（国债/LPR/OMO/M2）/ 全球（VIX/DXY/CNH/利差）/ 情绪（新增投资者）/ 经济（PMI/CPI/PPI/社融/出口）。月度⭐已更新 / ☆待更新；每日高频实时显示。
危机监测·趋势对比
监测SHIBOR隔夜、中美利差、PMI、社融增速、出口增速、VIX、铜金比共7项。与前值对比，趋势箭头↑恶化↓改善。评分：🔴2分危险 / 🟡1分关注 / 🟢0分安全；≥6高度警惕 / 3-5需要关注 / ＜3暂无异常。

🧬三重共识 - 说明

判定公式
主站 TOP10（total_score ≥70） ∩ 驾驶舱 A档 ∩ 基本面质量 A档，三者同时满足即严格共识。
分组展示
· 严格共识（3/3）：无条件优先看
· 优先观察（2/3，total_score≥75）：差1步
· 扩展观察（2/3，total_score<75）：差2步
历史追踪
