## 三、④ 无拉条：两个层次

### 3.1 折叠容器层（本卡自管，不走全站 `__foldOpen`）

**旧版走全站通用折叠** `__foldOpen`，其容器带 `max-height:72vh; overflow-y:auto`（`index.html` L5786 附近）⇒ 内容一多必出**纵向拉条**，正是主人截图点名不要的那条。

**新版**本卡**自管折叠** `window.__imaFold(id)`：只切 `box.style.display`（`'none'` ↔ `''`），**全程不设 `max-height`、不设 `overflow`** ⇒ 结构上不可能出现拉条。

### 3.2 表格横滚容器层（`overflow-x:auto` 连带拉条）

🔴 **这是本轮新发现的坑**：`_tableHtml` 容器原为 `<div style="overflow-x:auto;">`。

依据 **CSS Overflow Module Level 3 §3**：一个轴被设成非 `visible` 的滚动值（`auto`/`scroll`/`hidden`）时，另一轴的 `visible` 会被**计算成 `auto`**。因此只写 `overflow-x:auto` 会**连带**把 `overflow-y` 算成 `auto` ⇒ 只要内容（多行表格）超过容器高度，就出现纵向拉条。

**修法**：显式压掉 y —— `overflow-x:auto;overflow-y:hidden;`（`_tableHtml` 内，现已落地）。

> ⚠️ 全站另有 **10 处**同类 `overflow-x:auto` 容器（四量 / 三重 / 生命周期等，L5579 / L5643 / L5699 / L5736 / L6032 / L6559 / L7445 / L7537 / L8592 / L17170 附近）。本次**未动**（主人只对本卡提「不要拉条」）。若主人希望全站统一，可另开一轮，同样只需补 `overflow-y:hidden`。

## 五、两个致命坑（务必记住，别再踩）

### 坑 1｜🔴🔴 执行顺序铁律：同一函数体内必须「声明 → 定义 → 调用」

`var` 有变量提升但**赋值按序执行**；`window.X = fn` 是**普通赋值、完全无提升**。同一块内三者顺序错位会静默或报错：

- **错法 A**：调用排在 `var _grpHtml = {};` **之前** ⇒ 声明语句执行时把渲染刚填好的分组表**清空** ⇒ 折叠组静默展不开（不报错，最难查）。
- **错法 B**：调用排在 `window.__imaRenderMain = function(...)` **之前** ⇒ 运行期 `TypeError: window.__imaRenderMain is not a function`（真浏览器才抓到，jsdom `outside-only` 下 `onclick` 不执行，容易漏）。

**正解顺序（本卡现状，行号严格递增）**：

```
L7185   var _grpHtml = {};                       ① 声明
L7186   window.__imaGroupHtml = function(k){...}  ② 定义
L7189   window.__imaRenderMain = function(){...}  ② 定义
L7222   window.__imaFold = function(id){...}      ② 定义
L7236   window.__imaRenderMain();                 ③ 调用（在全部声明与定义之后）
```

### 坑 2｜🔴 替换式补丁的区间终点必须**含完整注释**，否则切碎代码

本轮改动 3 用「起点回溯 + 终点提示串」定位替换区间。**第一次** `END_HINT` 只写到 `  }; /* ← 闭合 __renderImaStrongStock` 而**漏了注释尾部 `（...） */`**，替换后残留裸文本 `（__imaFullPopup/__imaSetFilter 已移入其体内） */` ⇒ `SyntaxError: Invalid or unexpected token`。

**附带教训**：替换区间**吃掉了外层函数的闭合 `};`**，补回时须**原样还原**（包括那行注释），凭空多加一个 `};` 会变成 `Unexpected token ';'`。

**🔴 正解：替换式补丁落盘后，必须逐块跑 `node --check`**（见第六节）—— 单靠字符串计数自检**全部绿**也照样漏，这是本轮最硬的教训。
