### L2（待裁定）—— `--only` 参数不存在

- `GET /contents/api_push_raw.py?ref=main`（blob `2dd6645caaa2`，88,529 B / 1,437 行）正则实测：
  `--only` = **0 次**；`argparse` / `add_argument` / `sys.argv` / `parse_args` = **全 0 次**；`lhb` = 1 次且在**注释**里。
- 该脚本的推送面 = `walk_raw()`（`os.walk("raw_data")`，L514/L551）+ `walk_extra()`（**固定白名单**，13 个 `data/*.js`，L622）；
  若 workflow 传了 `PUSH_FILES` 则只推清单内文件。
- `v8_lhb_fetch.yml` **没有**传 `PUSH_FILES`，所以 `--only lhb` 被忽略后落到**全量回退**（5572 文件）——与 run#31 日志完全吻合。

  ⇒ 作者以为的分支**从来不存在**。
