## 四、5 条设计边界（上线前已自证，运行时未破）

1. **不误伤首构**：data 不存在 → `data 不存在（首次构建）` 不护栏。
2. **不误伤空 raw**：`_is_raw_empty_or_stale` 更前（L1098）拦截，护栏函数根本不会被调。
3. **不依赖 mtime 单源**：raw 真实时间 = `max(顶层 update_time, _meta.last_update, mtime)` 三源兜底（git checkout 会重置 mtime，见脚本 L334 注释）。
4. **不影响 detect-changes / 全量构建**：只跳过「覆盖动作」，`skipped += 1` 统计照常，CI 日志可读。
5. **不阻断正常推进**：data 无 update_time / raw 时间无法取得 → 全部走正常构建。
