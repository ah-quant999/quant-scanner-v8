### 3. workflow 修复（`.github/workflows/v8_build_deploy.yml` retry 环，+13/-0）

re-fetch 后、`git add` 前插入：
```bash
git checkout FETCH_HEAD -- index.html logic.html
timeout 180 python update_v8.py --only-cache-busters || echo "⚠️ retry 环 ?v 刷新失败，留给 reconcile 兜底"
```
语义：按最新 tip 刷新两个正文文件（= 外层 reset --hard 的同等保护），仅 data/ 等构建产物继续走 add；?v 重算失败不致命（15 分钟档 reconcile 兜底）。**新代码 build 不仅能防回退，还能把 mid-run 的正文推送吸收进 retry 提交**。YAML 解析 + `bash -n` + 插入行在 run 块内三重校验过。
