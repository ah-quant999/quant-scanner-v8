🥇三重共识 - 说明

判定公式
主站 TOP10（total_score ≥70） ∩ 基本面质量 A档，双维同时满足即共识。可信度最高（⭐⭐⭐⭐⭐）——2 个独立维度一致才入选，命中即高质量。
分组展示
· 严格共识（2/2）：无条件优先看
· 优先观察（1/2）：差1步（TOP10精选但缺基本面A）
评分·完整公式
总分 = 各因子按「数据来源 → 评判逻辑 → 加分区间」逐项量化后求和，最后归一化到 0~100。基础信号权重完全由 walk-forward 回测期望（胜率×收益，带收缩）驱动：对每个信号取其在 backtest_expectancy.json 的 T+10 edge，正 edge → 加分、负 edge → 扣分，彻底替代原拍脑袋的 +25 均权；权重再乘以 P1 置信度收缩（样本量 n/120 与 T+5/T+10 符号一致性，薄样本或符号矛盾 → 向 0 收缩，如缠论因 T+5 符号矛盾有效权重 ×0.5）。
市场级调节器：v8MarketGate() 择时门控作为全局情绪/市况调节器——仅 grind/panic 状态正常打分，其余状态对总分乘子降权，避免弱势市况下机械追高。
板块取主板块流入：板块共振取所属赛道净流入最强者（非全市场求和），并过滤业绩/指数/风格类非赛道标签，避免概念重叠重复计数与板块失血从不扣分。
原始分构成：基础(金钻+20/缠论+9/机构变红−26/上涨趋势−19) + 增强(~21) + 形态(~16) + 资金(~8) + 板块(~5) + 机构/事件(~7) + 基本面(−10~+40) + 回测反哺(±10) + 研究驱动因子(~13) + P4残差动量/门控(−6~0)。最终 total_score = min(100, 原始总分/130×100)；≥80 精选 / ≥70 观察。

📊CRDS 逆势龙头 - 算法说明

定位

输入与数据源
· 个股池：watch_result.json（来自 scanner.py watch 模式，即金股池/观察池股票），按数字代码去重。
· 个股K线：mootdx 通达信直连 bars() 为主（不受 BaoStock 封禁影响），东方财富 push2his K线 为兜底。
· 大盘：上证指数 000001 近10日K线。
· 注：mootdx.bars() 每约50次调用重建客户端+gc 以规避 socket 泄漏；CRDS 约需 176 次调用，必须周期重置。
三个核心条件（满足越多越好）
条件判定阈值/口径
① 10日≥2板近10个交易日涨停次数 ≥ 2主板涨停阈值 9%（留1%误差）；创业板/科创板 18%
② 大跌日逆势板至少1个涨停日对应大盘当日跌超阈值MARKET_DOWN_THRESHOLD = -1.5%

打分公式
AF = max(涨停且大盘跌那天的 个股涨幅 / |大盘当日跌幅|) # 大盘跌幅需 > 0.5% 才计 VR_peak = max(近10日成交额 / 近20日均成交额) TS_peak = max(近10日换手率 / 近20日均换手率) 逆势板占比 = zt_on_down / zt_count CRDS_raw = AF × min(VR_peak, 3) × (1 + 逆势板占比) / 3 CRDS_score = min(100, round(CRDS_raw × 10)) # 归一化并截断到 0~100

所有回测引擎统一采用 win / (win + loss)，平盘（收益=0）不计入胜率分母。避免一处平盘算输、另一处平盘剔除导致的口径打架。
幸存者偏差控制
通达信 60 日回测会累积每日金股池快照，用「最近 90 天内所有快照的并集」作为回测宇宙。这样可以纳入那些曾经入选、后来跌出池的股票，降低「只测现存强势股」导致胜率高估的问题。快照累积不足时，面板会标注「仍含幸存者偏差」。
买卖建议原则
最佳持有期判定优先看胜率与样本量双约束，样本不足信号不会直接推荐，避免偶然性。
