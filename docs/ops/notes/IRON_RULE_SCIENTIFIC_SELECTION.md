# 铁律 · 科学选股方法论（收益率最高 ≠ 回测最高）

> 适用范围：quant-scanner-v8 选股算法（`algorithms/generate_top10.py`）所有因子、权重、排序逻辑的设计与变更。
> 2026-11-02 主人令固化：只要「收益率最高、最科学」的选股方法、算法、因子。

## 〇、核心立场（先回答「回测真的有用吗」）

回测是量化选股的**必要验证工具，不是选股依据本身**。

- ✅ **有用**：检验因子是否有经济/统计逻辑支撑、样本外是否稳健、交易成本下是否成立、不同市场状态下是否衰减。
- ❌ **有害用法（本仓曾犯）**：**「看哪个回测数字最高就接哪个因子 / 把回测收益数字直接当权重」** —— 这是 data snooping（数据窥探）过拟合，挑出的「最高」大概率是噪声，实盘必然衰减。

**最科学的选股 = 逻辑驱动 + 样本外验证 + 多因子正交 + 风险约束 + 衰减监控**，不是「历史回测收益率最高的因子」。

⚠️ **禁止承诺「本方法收益率最高」**：超额收益会随市场状态（牛/熊/震荡）和因子拥挤度衰减。科学方法追求的是「样本外稳健前提下的最高收益」，没有永远第一的单一方法。任何宣称「本因子历史收益 +46% 所以必赚」的话术都是 data snooping 陷阱。

## 一、因子科学等级（准入门槛）

| 等级 | 标准 | 能否进主排序 | 权重上限 |
|---|---|---|---|
| **S 级** | 有经济/统计逻辑 + 样本外(out-of-sample) IC>0 + 多周期稳健 | ✅ 可进主排序 | 不限 |
| **A 级** | 有逻辑 + in-sample 有效但缺 OOS 证据 | ⚠️ 仅辅助 | ≤±15 |
| **B 级** | 纯 in-sample 拟合、无逻辑 / 无 OOS | ❌ 禁止进排序 | 0（仅展示） |

### 当前因子定级（落到代码常量，2026-11-02）

- **`RPS 动量项`**（`_rps_prepass`）：逻辑成立（动量/相对强度异象，Jegadeesh-Titman 学术证实）→ **S 级，主区分项 ±55**。
  实现用**当下价格数据**（个股 60/120 日区间收益）做候选池横截面排序，**非回测拟合参数**；权重依据 = 动量异象学术证据 + 样本外 IC，**禁止取自 in-sample 回测收益数字**（如「T+250 +46%」）。
- **`expected_return_term`**（`BT_BY_SIGNAL`）：基于 **in-sample 回测** ret5/ret10 中心化；且 HC 高信念模式下 sig_tuple 全员同值 → **完全不分高下（失效）** → **A 级降级**，权重 ±55→**±15**，仅作跨组合辅助区分（非 HC 模式下有微弱区分力）。
- **`winrate`**（`WR_CONF_WEIGHT`）：历史胜率微调 → **A 级**，置信微调 ±11，不作主排序。

## 二、选股方法标准（算法必须遵守）

1. **逻辑先于数据**：任何新因子先有可解释的经济/行为逻辑，再做验证；禁止「回测好就上」。
2. **样本外验证 gate**：S 级因子上线前必须有 walk-forward / out-of-sample 验证（IC>0、IR 稳定）；证据缺口默认关闭（`V8_*=0`）。
3. **多因子正交化**：相关因子做横截面中性化（现有 `_raw_noform` 中性化重建机制保留），禁止共线因子双计。
4. **风险约束优先**：因子分再高，触及 P1 风险闸（历史 T+5 胜率<线、质差一票否决）仍降级/剔除 —— 坏行情不硬凑。
5. **成本现实**：所有回测/预期收益口径必须含交易成本（现有 next_open + 扣费口径保留）。

## 三、禁止事项（红线）

- 🔴 禁止用**单一 in-sample 回测收益数字**直接设定因子权重（如把「T+250 +46%」当权重依据）。
- 🔴 禁止把 in-sample 回测最高收益当成「真实收益率最高」对外宣称。
- 🔴 禁止为制造「top 在变」而人为扰动算法（沿用 TOP3 停滞铁律）。
- 🔴 禁止 data snooping：在大量因子/参数里挑「最好」的那个直接上线。

## 四、监控（防衰减）

- **因子样本外衰减监控**：滚动计算各 S 级因子 IC，连续 N 周期 IC<0 → 自动降级并告警。
- **TOP3 停滞自查**：沿用 `IRON_RULE_TOP3_STABILITY.md`（连续≥3 日不变 → 自查 + 写入铁律）。
- **回测口径守卫**：`pre_deploy_audit.py` 第 9 项持续守护 `backtest_expectancy.json` 新口径。
