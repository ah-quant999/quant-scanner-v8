## 五、踩坑记录（本次新增，均已沉淀）

### 5.1 🔴 内联块搬迁的「壳子/函数分离」陷阱

**症状**：容器搬到新页后永久显示「加载中…」，控制台无报错。
**根因**：原实现的渲染逻辑是**内联在 `__renderObsPlatform` 函数体里**的（不是独立函数）。只搬容器标签，函数体不搬 ⇒ 无人写 `innerHTML`。
**判据**：搬迁前先 grep 该卡容器 id 是否在**任何派发名单**里；不在 ⇒ 必须同步抽函数 + 补派发 + 加退避重试。
**本项目同类前科**：2026-09-12 `_fillMahoroCard` 迁页后无触发 ⇒ 卡永久「加载中」（同款）。

### 5.2 🔴 pane 闭合行与卡片尾行「注释同形」导致误搬

**症状**：搬走 K 卡后，`obsPaneMacro` 丢失闭合 ⇒ 相邻 pane 被吞（本项目 P0 级事故形态）。
**根因**：K 卡尾行注释写的是「…吞掉了 `/obsPaneMacro` 的闭合…」，字样里含 `/obsPaneMacro`；而 pane 真正闭合行是 `hm += '</div>'; // /obsPaneMacro`。用模糊锚定位时，**尾行注释先被命中**。
**修法**：区块边界一律用**唯一性断言**（`count()==1`）+ 取**行首缩进+完整行**作锚，禁止用「含某字样」做边界。
**本次实录**：v1 补丁因此误删 pane 闭合（`obsPaneMacro` 9→8），v2 修正边界后恢复 9。

### 5.3 🔴 「含该串的行数」≠「该串出现次数」再犯

**实录**：断言 K 段 `_kShape` 出现次数，我按「行数」估成 14，`count()` 实测 **16** ⇒ 断言直接 raise，救回一次盲改。
**纪律**：断言值**必须 `count()` 实测后再写入**，不得心算/估算。

### 5.4 ⚠️ 注释文本内的 HTML 字面量污染统计

**实录**：我在新注释里写了 `'</div></div>'` 作为说明文字，导致「函数内 div 配平」统计出 -2（应为 +1），一度误判为真缺陷。
**修法**：做标签配平统计前**先剥离行注释**（正则剔 `//` 到行尾，注意别误伤 URL 里的 `//`）。

### 5.5 ⚠️ CRLF 文件改写的锚件必须显式带 `\r\n`

**实录**：`logic.html` 是 CRLF，我脚本里多行锚件用裸 `\n` ⇒ `count()==0` 直接失败。
**修法（本次采用）**：先 `replace('\r\n','\n')` 归一为 LF 版 → 在 LF 版上改写 → 写盘前 `replace('\n','\r\n')` 还原 + 断言裸 LF=0。比逐个手写 `\r\n` 更不易漏。
